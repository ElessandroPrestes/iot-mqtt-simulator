# Perfis

Perfis adaptam o Universal SDD a uma tecnologia, domínio ou nível de risco.

Um perfil deve declarar escopo, pré-requisitos, comandos, padrões adicionais,
gates, responsáveis e compatibilidade. Ele pode tornar a baseline mais rigorosa;
qualquer redução exige exceção aprovada. Perfis oficiais por tecnologia estão
planejados para a v2.0.
